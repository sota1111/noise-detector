# 🎵 音声識別評価ダッシュボード

音声識別システムのテスト結果をリアルタイムで監視・分析するためのWebベースダッシュボードです。

## 🚀 クイックスタート

### 起動方法

```bash
# プロジェクトルートディレクトリから実行
export PYTHONPATH=/home/sota/dev/2025/hils/noise-detector/htf_project:$PYTHONPATH && python3 audio_hils_system/waveform/dashboard/run_dashboard.py
```

起動後、ブラウザで以下のURLにアクセス:
**http://localhost:8050**

### 停止方法
`Ctrl+C` を押してダッシュボードを停止します。

## 📋 システム要件

### 依存ライブラリ
- Python 3.10+
- Dash ≥2.14.0
- Dash Bootstrap Components ≥1.5.0 
- Plotly ≥5.15.0
- Pandas ≥1.5.0

必要なライブラリは起動時に自動でインストールされます。

## 🎛️ 主な機能

### 1. **マルチタブインターフェース**
- **統計タブ**: パフォーマンス統計とメトリクス
- **詳細タブ**: 詳細分析とタイムライン表示
- **波形タブ**: オーディオ波形の可視化

### 2. **セッション管理**
- テストセッションの自動検出と選択
- リアルタイムデータ更新（30秒間隔）
- セッション形式: `YYYYMMDD_HHMMSS`

### 3. **統計分析**

#### **パフォーマンスメトリクス**
- 総テスト数
- 成功率（正確に識別されたサンプルの割合）
- 平均信頼度スコア
- 平均応答時間

#### **可視化チャート**
- **精度バーチャート**: カテゴリ別識別精度
- **信頼度ヒストグラム**: 信頼度スコアの分布
- **応答時間ボックスプロット**: カテゴリ別応答時間分布
- **混同行列**: 予測対実際のカテゴリヒートマップ

### 4. **詳細分析**
- **パフォーマンスタイムライン**: 複数セッション間の精度推移
- **テスト結果テーブル**: 詳細なテストごとの結果表示
- **フィルタリング機能**: カテゴリ別データフィルタリング

### 5. **波形可視化**

#### **デュアル解像度表示**
- **標準解像度**: 全オーディオファイルの波形データ
- **高解像度**: 最初の1秒間の詳細表示
- **入出力電圧トレース**: 入力と出力信号の比較表示
- **時間領域解析**: カスタマイズ可能なスケールでの電圧対時間プロット

#### **対応データ形式**
- 入力電圧測定値
- 出力電圧測定値
- 時間インデックス付きデータポイント

### 6. **インタラクティブ制御**
- **セッション選択**: ドロップダウンメニューで特定セッションを選択
- **カテゴリフィルタリング**: マルチセレクトチェックボックス
- **手動更新**: リフレッシュボタン
- **自動更新**: 30秒間隔の自動データ更新

## 📊 対応データ形式

### 統計データ（CSV）
必要列: `test_number`, `filename`, `category`, `success`, `confidence`, `response_time`, `predicted_category`, `identification_correct`

### 波形データ（CSV）
必要列: `Time(s)`, `Input_Voltage(V)`, `Output_Voltage(V)`

### セッションデータ
- セッションサマリーファイル: `session_*_summary.md`
- 統計CSVファイル: `*_statistics.csv`
- バッチレポートファイル: `*_batch_report.md`

## 📁 データパス

ダッシュボードは以下のパスからデータを自動検出します:

```
/output/reports/           # 新しいレポートパス
/data/output/reports/      # レガシーレポートパス
```

## 🐛 トラブルシューティング

### 起動時のエラー
1. **モジュールが見つからない**: PYTHONPATHが正しく設定されているか確認
2. **ライブラリエラー**: `pip install -r dashboard_requirements.txt` で手動インストール
3. **ポート使用中**: ポート8050が他のプロセスで使用されていないか確認

### データが表示されない
1. **データパスの確認**: `/output/reports/` または `/data/output/reports/` にデータファイルが存在するか確認
2. **ファイル形式**: CSV/MDファイルが正しい形式になっているか確認
3. **セッション形式**: セッションIDが `YYYYMMDD_HHMMSS` 形式になっているか確認
